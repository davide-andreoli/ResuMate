# Changelog

## 0.2.0

### New features

- Added conversation memory and support for multiple conversations
- Added support for agent handoffs
- Added resume creation agent
- Added resume template editing agent

### Improvements

- Improved UI/UX of the app
- Updated the API interface to better respect RESTful principles
- Added more comprehensive tests for most components of the app

### Bug fixes

- Fixed a few bugs

## 0.1.0

This is the first release of the app.

### Features

#### Core Features

- Add and manage your professional experience
- Render your resume using multiple customizable templates

#### Agent specific features:

- Chat with an AI agent about your resume
- Receive suggestions on how to improve specific sections
- Allow the agent to directly modify your resume
